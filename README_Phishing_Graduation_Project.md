## Investigation Workflow
1. Analyze email headers: From, Reply-To, Return-Path and Received chain.
2. Review SPF, DKIM and DMARC where available.
3. Inspect URLs and domains for phishing indicators.
4. Inspect attachments and calculate hashes when applicable.
5. Extract IOCs: sender, URLs, domains, IPs and file hashes.
6. Document findings and submit the challenge.
